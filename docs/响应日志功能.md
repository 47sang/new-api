## 一、需求背景

当前的 `content` 字段仅存储计费描述字符串（如"模型倍率 1.23，补全倍率 2.00"），**不包含**用户发送给模型的请求内容（messages）和模型返回的响应内容。前端日志详情弹窗无法查看完整的 API 请求和响应。

## 二、架构设计

### 2.1 整体数据流

```
                         ┌──────────────┐
                         │   Gin 中间件  │  ← 新增：ResponseRecorder 包装 c.Writer
                         └──────┬───────┘
                                │
                    ┌───────────▼────────────┐
                    │   controller/relay.go   │
                    │   (主 relay 入口)        │
                    └───────────┬────────────┘
                                │
              ┌─────────────────┼─────────────────┐
              │                 │                 │
       ┌──────▼──────┐  ┌──────▼──────┐  ┌──────▼──────┐
       │ 请求体已捕获  │  │  业务逻辑    │  │ 响应体捕获   │
       │ BodyStorage │  │  重试/计费   │  │ ResponseRec │
       │ (已有)      │  │             │  │ (新增)       │
       └──────┬──────┘  └──────┬──────┘  └──────┬──────┘
              │                 │                 │
              └─────────────────┼─────────────────┘
                                │
                    ┌───────────▼────────────┐
                    │  异步保存 (gopool)      │
                    │  request_id → 新表      │
                    └─────────────────────────┘
```

### 2.2 数据库设计

**单独建表 `request_response_logs`**（存入 LOG_DB，与 logs 表同一数据库）：

```go
type RequestResponseLog struct {
    Id             int64  `json:"id" gorm:"primaryKey"`
    RequestId      string `json:"request_id" gorm:"type:varchar(64);uniqueIndex;not null"`
    RequestBody    string `json:"request_body" gorm:"type:mediumtext"`
    ResponseBody   string `json:"response_body" gorm:"type:mediumtext"`
    CreatedAt      int64  `json:"created_at" gorm:"bigint;index"`
    IsCompleted    bool   `json:"is_completed" gorm:"default:false"`
    ResponseStatus int    `json:"response_status" gorm:"default:0"`
}
```

**关联关系：**

```
logs 表                          request_response_logs 表
─────────────────                ───────────────────────────────
id                               id                 主键
user_id                          request_id    唯一索引 ← ─ ─ ─ ─ ┘
content                          request_body  TEXT/MEDIUMTEXT
request_id ──────────────────────┘ response_body TEXT/MEDIUMTEXT
upstream_request_id               created_at   时间戳
...                              is_completed 是否完成
                                 response_size 响应大小(字节)
                                 status_code  状态码
```

### 2.3 为什么不复用现有字段

| 维度 | 单独建表 | 塞进 `content` | 塞进 `other` |
|---|---|---|---|
| 对现有查询性能影响 | 零 | 大——`logs` 是最频繁查询的表 | 中 |
| 能存多大 | 无限制 (TEXT/MEDIUMTEXT) | 受限于现有列宽 | JSON 编码后膨胀 30%+ |
| 可独立清理 | 支持，按需设置 TTL | 不支持 | 不支持 |
| 前端查询效率 | 按 `request_id` 精确查询，快 | 无索引，慢 | 无索引，慢 |
| 对现有功能的影响 | 零 | 会破坏现有 content 显示 | 会污染 other 的结构化数据 |

### 任务 2：创建 RequestResponseLog 数据模型

**新建文件：** `model/request_response_log.go`

```go
package model

import (
    "time"
    "github.com/QuantumNous/new-api/common"
    "gorm.io/gorm"
)

type RequestResponseLog struct {
    Id             int64  `json:"id" gorm:"primaryKey"`
    RequestId      string `json:"request_id" gorm:"type:varchar(64);uniqueIndex;not null"`
    RequestBody    string `json:"request_body" gorm:"type:mediumtext"`
    ResponseBody   string `json:"response_body" gorm:"type:mediumtext"`
    CreatedAt      int64  `json:"created_at" gorm:"bigint;index"`
    IsCompleted    bool   `json:"is_completed" gorm:"default:false"`
    ResponseStatus int    `json:"response_status" gorm:"default:0"`
}

func SaveRequestResponseLog(log *RequestResponseLog) error {
    if !common.RequestResponseLogEnabled {
        return nil
    }
    log.CreatedAt = common.GetTimestamp()
    return LOG_DB.Create(log).Error
}

func UpdateRequestResponseLog(requestId string, responseBody string, statusCode int) error {
    if !common.RequestResponseLogEnabled {
        return nil
    }
    return LOG_DB.Model(&RequestResponseLog{}).
        Where("request_id = ?", requestId).
        Updates(map[string]interface{}{
            "response_body":   responseBody,
            "is_completed":    true,
            "response_status": statusCode,
        }).Error
}

func GetRequestResponseByRequestId(requestId string) (*RequestResponseLog, error) {
    var log RequestResponseLog
    err := LOG_DB.Where("request_id = ?", requestId).First(&log).Error
    if err != nil {
        return nil, err
    }
    return &log, nil
}

func DeleteOldRequestResponseLogs(beforeTimestamp int64) (int64, error) {
    result := LOG_DB.Where("created_at < ?", beforeTimestamp).Delete(&RequestResponseLog{})
    return result.RowsAffected, result.Error
}
```

### 任务 4：实现 ResponseRecorder 中间件

**新建文件：** `middleware/response_recorder.go`

```go
package middleware

import (
    "bytes"
    "io"
    "net/http"
    "sync"
    "sync/atomic"

    "github.com/QuantumNous/new-api/common"
    "github.com/QuantumNous/new-api/model"
    "github.com/QuantumNous/new-api/types"

    "github.com/gin-gonic/gin"
)

// responseRecorder 包装 gin.ResponseWriter，捕获响应体
type responseRecorder struct {
    gin.ResponseWriter
    body *bytes.Buffer
    mu   sync.Mutex
}

func (r *responseRecorder) Write(data []byte) (int, error) {
    r.mu.Lock()
    defer r.mu.Unlock()
    // 检查大小限制
    if r.body.Len()+len(data) > common.RequestResponseLogMaxSize {
        r.body.WriteString("\n...[truncated, exceeds max size]")
        return r.ResponseWriter.Write(data)
    }
    r.body.Write(data)
    return r.ResponseWriter.Write(data)
}

func (r *responseRecorder) WriteString(s string) (int, error) {
    return r.Write([]byte(s))
}

// captureResponse 捕获请求的响应体（用于非流式请求）
func CaptureResponse(c *gin.Context, requestId string) {
    if !common.RequestResponseLogEnabled {
        return
    }

    // 只捕获 API relay 路径
    if !isRelayPath(c.Request.URL.Path) {
        return
    }

    // 不捕获流式响应（流式由 StreamScannerHandler 处理）
    if c.GetBool(constant.ContextKeyIsStream) {
        return
    }

    rec := &responseRecorder{
        ResponseWriter: c.Writer,
        body:           &bytes.Buffer{},
    }
    c.Writer = rec

    c.Next()

    // 异步保存响应
    if rec.body.Len() > 0 {
        go func() {
            model.UpdateRequestResponseLog(requestId, rec.body.String(), c.Writer.Status())
        }()
    }
}
```

### 任务 5：在 Relay 入口集成 ResponseRecorder

**文件：** `controller/relay.go`

在 `Relay()` 函数中，`request, err := helper.GetAndValidateRequest(c, relayFormat)` 之后插入：

```go
func Relay(c *gin.Context, relayFormat types.RelayFormat) {
    requestId := c.GetString(common.RequestIdKey)

    // ── 新增：保存请求体 ──────────────────────────────────
    if common.RequestResponseLogEnabled && isRelayPath(c.Request.URL.Path) {
        bodyStorage, bodyErr := common.GetBodyStorage(c)
        if bodyErr == nil {
            if reqBytes, bytesErr := bodyStorage.Bytes(); bytesErr == nil {
                // 重新设置 body 以便后续读取
                c.Request.Body = io.NopCloser(bytes.NewReader(reqBytes))
                gopool.Go(func() {
                    model.SaveRequestResponseLog(&model.RequestResponseLog{
                        RequestId:   requestId,
                        RequestBody: string(reqBytes),
                    })
                })
            }
        }
    }
    // ─────────────────────────────────────────────────────

    var err *types.NewAPIError
    // ... 原有逻辑不变
}
```

同时在 `Relay()` 函数的返回前（成功路径），添加响应捕获：

// GetRequestResponseLog 获取请求/响应详情

func GetRequestResponseLog(c *gin.Context) {
    requestId := c.Query("request_id")

        return

}

### 任务 9：定期清理过期记录

**新建文件：** `service/request_response_cleanup.go`

```go
package service

import (
    "time"
    "github.com/QuantumNous/new-api/common"
    "github.com/QuantumNous/new-api/model"
)

func StartRequestResponseLogCleanup() {
    if !common.RequestResponseLogEnabled {
        return
    }
    go func() {
        ticker := time.NewTicker(24 * time.Hour)
        defer ticker.Stop()
        for range ticker.C {
            beforeTimestamp := time.Now().AddDate(0, 0, -common.RequestResponseLogTTLDays).Unix()
            deleted, err := model.DeleteOldRequestResponseLogs(beforeTimestamp)
            if err != nil {
                common.SysError("failed to cleanup request_response_logs: " + err.Error())
            } else if deleted > 0 {
                common.SysLogf("cleaned up %d old request_response_logs records", deleted)
            }
        }
    }()
}
```

**启动时调用：** 在 `main.go` 或服务初始化代码中：

```go
service.StartRequestResponseLogCleanup()
```

## 八、风险与缓解

| 风险 | 影响 | 缓解措施 |
|---|---|---|
| 存储膨胀 | 高频场景下日志增长快 | 默认关闭 + 自动清理（7 天 TTL） |
| 内存占用 | 响应缓存 buffer 占用内存 | 设置大小上限（2MB），超出截断 |
| 敏感信息 | 请求体可能包含 API key | 记录前脱敏处理 |
| 性能影响 | 包装 Writer 有微小开销 | 默认关闭，开启时只影响该功能请求 |
| 大响应体 | 图像生成/长文本可达 MB | 大小限制 + 前端分页/折叠 |
| Docker volume | 数据目录需正确挂载 | 使用绝对路径 + 验证 |
