# PRODUCT.md — 用量分析页的模型 Token 缓存拆分

## 摘要

在管理员的用量分析页（`/dashboard/usage`）上，把每个模型的 token 总量拆成「缓存读取 / 非缓存读取 / 输出」三类：
在用量汇总柱形图上选中某个模型后展示该模型的三类构成与占比；同时在卡片内新增一块全模型的缓存对比数据（列表 + 100% 堆叠横条），让管理员能直接判断哪个模型缓存打得满、输出占比高。

Figma: none provided —— UI 以用户提供的用量分析页现状截图为唯一视觉参考（汇总大数字 + 按模型堆叠柱形图 + Top models 榜单 + Activity 热力图），新模块沿用该页既有卡片与排版语言。

## 目标 / 非目标

**目标**

- 管理员在用量分析页内回答「这个模型的 token 花在哪了」，不需要再去翻逐条日志。
- 所有模型横向可比：谁的输入侧缓存命中率高、谁的输出占比高。
- 拆分数据与柱形图同源同口径，数字能对上。

**非目标**

- 不做缓存写入（cache write / cache creation）的展示与统计。
- 不做普通用户（非管理员）视角，不新增自助页面。
- 不改数据看板其他 Tab（概览 / 模型 / 流向 / 用户）的任何行为。
- 不改计费、定价、结算逻辑；本次只新增统计列与展示。
- 不做历史数据回填。

## 行为

### 一、数据契约（对读写用量汇总数据的代码成立）

1. 用量汇总数据源新增三个非负整数字段：**非缓存读取**（`uncached_input_tokens`）、**缓存读取**（`cache_read_tokens`）、**输出**（`output_tokens`）。三者默认值为 0，缺失或为空的存量数据一律按 0 处理。

2. 三个字段的口径（对同一次请求）：
   - **输出** = 该次请求的输出 token 数；
   - **缓存读取** = 该次请求命中缓存的输入 token 数；
   - **非缓存读取** = 该次请求的输入 token 数；当该次请求的输入口径**本身已包含**缓存命中时，需先扣除缓存读取部分，下限为 0。

3. 不变量：三个字段各自**永不为负**，且各自**不超过**同一次请求的总量（`token_used`）。当输入口径已包含缓存命中时，「非缓存读取 + 缓存读取 + 输出」等于 `token_used`；当输入口径不含缓存时，三者之和**小于或等于** `token_used`（差额为该次请求的缓存写入，本期不统计）。

4. 累加不变量：用量汇总数据按（用户、模型、小时、分组、令牌、渠道、节点）键聚合累加。同一键的多次累加必须让三个新字段与既有的次数、额度、总量**同步累加**；任何一条累加路径遗漏新字段都会导致周期刷新后拆分数据丢失，这是明确禁止的回归。

5. 写入时机：新字段随每次消耗记账一并写入，与既有的总量字段同一笔完成；不同步、事后补算的行为不允许。

6. 存量数据：升级前已写入的行三个字段为 0。因此升级后的一段时间内，较早时间范围的拆分数据会显示为空或 0，这是已知且被接受的行为，产品文案不得把它伪装成「该模型没有缓存」。

7. 聚合查询接口（管理员按天取用量汇总数据）在「按天」与「按天 + 模型」两种模式下都返回三个新字段的求和值；字段名与 JSON 键一致；仅管理员可访问，非管理员返回原有的未授权响应，行为不变。

8. 其他既有数据接口的既有数值不变；新字段可以出现在响应中，但不得改变任何既有字段的含义与取值。

### 二、选中模型的 Token 拆分面板

9. 页面默认状态：卡片右侧为 Top models 榜单，与当前版本完全一致。

10. **选中入口有两个，效果相同**：
    - 点击柱形图图例中的某个模型项（柱形图图例本就支持单选隔离该模型）；
    - 点击 Top models 榜单中的某一行（该行是可键盘聚焦、可用回车/空格触发的按钮）。
    两个入口都指向同一个「选中模型」状态。

11. 选中后，卡片右侧由 Top models 榜单**切换**为该模型的「Token 拆分」面板，柱形图保持该模型的隔离显示。面板内容包括：
    - 标题：面板名称 + 被选中的模型名；
    - 三类 token 的数值与占三项合计的百分比：缓存读取、非缓存读取、输出（百分比按三项合计为分母，三者相加为 100%）；
    - 一个 100% 三段堆叠条，三段按同一顺序与同一组语义色渲染；
    - 三项合计的数值；
    - **输入侧缓存命中率** = 缓存读取 ÷（缓存读取 + 非缓存读取），以百分比展示；当输入侧合计为 0 时显示占位符（如 `—`），不显示 0% 或 NaN。

12. 数值格式：与页面既有数字一致——默认紧凑格式（如 `1.2亿`、`274M`），悬浮或聚焦展示完整精确值；
    百分比复用项目统一的百分比格式化工具（最多两位小数），不为本面板单独定制精度。

13. **取消选中**有两种方式：面板内的「返回榜单」按钮；再次点击柱形图图例中已选中的同一模型项。取消后恢复 Top models 榜单。

14. 选中态在以下情况**复位为未选中**：切换时间范围、切换指标、页面重新挂载。复位时不得展示上一个时间范围的拆分数据。

15. **指标限制**：Token 拆分只在指标为「Token」时有意义。当指标为「消费」或「请求数」时：
    - 卡片右侧显示一句提示文案（说明 Token 拆分仅在 Token 指标下可用），不渲染拆分面板；
    - 选中态本身仍被记录（切回 Token 指标时是否恢复选中由技术方案决定，但不得展示与当前指标矛盾的数字）。

16. **无拆分数据时**：所选时间范围内该模型三个字段全为 0（典型原因是升级前的历史行、或该模型仅有任务类计费）时，面板显示空状态文案（如「所选时间范围内该模型暂无缓存拆分数据」），**不得**渲染三条 0% 的假占比条。

17. **加载与失败**：拆分数据未就绪时面板区域显示骨架屏；取数失败时显示错误占位与「重试」按钮，重试只重新请求失败的数据，不影响柱形图与榜单。

### 三、全模型缓存占比（榜单下方）

18. 位置：Usage summary 卡内、Top models 榜单（或拆分面板）下方，独立成一个带标题的小节，标题为「模型缓存占比」并注明口径为 Token。

19. 该小节包含两种形态，数据同源，在同一行内左右并排（窄屏上下堆叠）：
    - **列表**：每行展示模型名、三类 token 数值、三项合计、输入侧缓存命中率；按三项合计降序，合计相同时按模型名字典序；最多 20 行，超出部分合并为一行「其他」——「其他」行的三类数值为其余模型之和，命中率按该行合计重算，不取平均值。
    - **图表**：每个模型一条 100% 三段堆叠横条，条目与列表一致（前 20 名 + 其他）；悬浮任一横条展示该模型的三类精确数值与输入侧缓存命中率。

20. **过滤规则**：三个字段全为 0 的模型（无拆分数据）不出现在列表与图表中；柱形图中因长尾合并而产生的「其他」是展示用聚合项，不是真实模型，不得出现在本节。

21. **颜色**：三类 token 使用固定的语义色（缓存读取 / 非缓存读取 / 输出各一色），亮暗主题下均可辨，对比度满足 WCAG 2.1 AA；不复用按模型分配的柱形图色板，避免与模型颜色混淆。

22. **空状态**：所选时间范围内所有模型都没有拆分数据时，本节显示空状态文案（说明升级前的历史数据没有拆分统计，而非「没有用量」）；范围内完全没有用量时沿用页面既有空状态。

23. **指标限制**：与拆分面板一致，本节同样只在「Token」指标下渲染；其他指标下不占位、不显示。

24. 列表行数与图表条目数在窄屏下不换行破碎：窄屏时列表保留模型名 + 合计 + 命中率三列，三类数值可隐藏或折叠；图表横条宽度自适应，不出现横向滚动条以外的裁剪。

### 四、跨模块一致性

25. 页面既有行为全部不变：时间范围选择、指标切换、汇总大数字与环比、柱形图堆叠与 tooltip、Top models 榜单排序与进度条、Activity 热力图、刷新按钮、错误与重试、空状态。

26. 国际化：本节所有新增文案（面板标题、三类 token 名称、合计、输入侧缓存命中率、空状态、指标限制提示、返回榜单按钮）均走界面翻译，七种语言补齐，不得出现硬编码中文或英文。

27. 数字与金额格式化复用项目既有格式化工具与语言环境转换规则，不得自行 `toLocaleString` 或拼接单位。

28. 数据新鲜度口径沿用既有约定：页面展示的是按小时聚合落库的统计快照，与日志明细可能有分钟级差异；本节同样不承诺实时性，也不展示「数据截至」时间戳。

29. 可访问性：拆分面板与缓存占比小节都有可访问名称；堆叠条提供文本等价信息（模型名 + 三类占比）；所有可点击的选择入口（榜单行、返回按钮）可键盘聚焦与触发，焦点顺序合理，装饰性色块 `aria-hidden`。
