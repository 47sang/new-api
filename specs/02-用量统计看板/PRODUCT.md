# PRODUCT.md — 用量统计看板（管理员全站视角）

## 摘要

为管理员新增一个全站用量统计页面：以 OpenRouter Usage 页面为参考，集中展示每日 Token 用量、各模型 Token/消费/请求排行、以及 GitHub 风格的年度活跃热力图。入口位于侧边栏「数据看板」菜单项下方，同时作为数据看板的一个新 Tab（`/dashboard/usage`）。

Figma: none provided —— UI 以用户提供的 OpenRouter Usage 页面三张截图为唯一视觉参考（汇总大数字 + 环比、每日按模型柱状图、Top models 榜单、Activity 热力图）。

## 目标 / 非目标

**目标**
- 管理员在一个页面内快速回答三个问题：每天用了多少、每个模型用了多少、发起了多少次请求。
- 支持三种指标切换：Token / 消费 / 请求数，全页所有模块跟随当前指标联动。
- 完整复刻 OpenRouter 的 Activity 年度热力图及其四个统计值。

**非目标**
- 不做个人（普通用户自助）视角，页面仅管理员可见。
- 不复刻 OpenRouter 截图中的「API keys」卡片（与本需求无关）。
- 不做自定义起止日期选择器（仅提供预设时间范围）。
- 不修改现有数据看板四个 Tab（概览/模型/流向/用户）的任何行为。

## 行为

### 入口与可见性

1. 侧边栏「常规」组中「数据看板」菜单项的**正下方**新增一个菜单项「用量分析」，仅管理员（role ≥ 10）可见；点击进入 `/dashboard/usage`。
2. 数据看板页内的 section Tab 列表中同样出现「用量分析」Tab（仅管理员可见），与侧边栏入口指向同一页面；两个入口切换时高亮状态保持一致。
3. 非管理员用户：侧边栏与 Tab 均不出现该入口；直接访问 `/dashboard/usage` 时重定向到数据看板默认页（不渲染任何统计内容）。
4. 后端数据接口必须做管理员鉴权，非管理员调用返回 401/403，前端据此引导至登录或展示无权限提示。

### 页面结构与工具行

5. 页面标题为「用量分析」。标题行下方提供两个全局控件：
   - **时间范围选择**：预设三档——最近 7 天（默认）/ 最近 30 天 / 最近 90 天。切换后柱状图、Top models、汇总大数字、环比全部刷新。
   - **指标切换**：三个选项——Token（默认）/ 消费 / 请求。切换后汇总大数字、环比、柱状图 Y 轴、Top models 排序与数值、热力图颜色与统计值全部联动。
6. 指标定义（全站聚合）：
   - **Token**：`token_used` 求和（输入 + 输出总 token 数，不拆分）。
   - **消费**：`quota` 求和，按系统既有金额换算规则显示（与现有数据看板的消费显示一致）。
   - **请求**：`count` 求和（调用次数）。

### Usage summary 汇总卡

7. 汇总大数字：当前指标在所选时间范围内的总量。数字超过一定长度时使用紧凑格式（如 `274M`、`1.2K`），完整精确值通过 tooltip 或悬浮展示。
8. 环比变化：与**紧邻的上一个等长时间段**比较（选最近 7 天则对比再往前 7 天），显示 `↑ +36.4%` 或 `↓ -36.4%` 并附「vs 上一个 7 天」说明文案：
   - 上升显示绿色、下降显示红色（与 OpenRouter 一致；消费指标不反转颜色语义）。
   - 上一周期总量为 0 且当前 > 0 时，显示「新增」徽标，不显示百分比。
   - 两个周期均为 0 时显示 `0%`，无箭头。
9. 汇总卡与柱状图同处一个卡片区域，右侧为 Top models 榜单（桌面端左右两栏，窄屏上下堆叠）。

### 每日按模型柱状图（Daily by model）

10. 以「天」为 X 轴单位、当前指标为 Y 轴的**按模型堆叠**柱状图；同一模型在所有日期中使用同一颜色，颜色在指标切换间保持稳定。
11. 悬浮任一日期柱体：tooltip 展示该日期的日期文本、各模型数值明细与当日合计。
12. 图例展示当前时间范围内出现的模型及颜色。当模型数量超过一个上限（如 12 个）时，柱状图仅堆叠用量排名靠前的模型，其余合并为「其他」一种颜色，避免图例与颜色不可辨；Top models 榜单不受影响，仍列出全部模型。
13. 所选时间范围内某天完全没有数据时，该日期仍出现在 X 轴上（空柱），保证时间轴连续无断点。
14. 整个时间范围无任何数据时，柱状图区域显示空状态文案（如「所选时间范围内暂无用量数据」）。

### Top models 榜单

15. 标题为「Top models」并注明当前排序依据（by Token / by 消费 / by 请求数）。
16. 列出所选时间范围内当前指标用量最高的模型（默认前 10）：每行包含模型名、数值（紧凑格式）、以及一条水平进度条，长度为该模型数值除以榜首数值的比例；榜首满条。
17. 排序始终跟随当前指标切换；行数不足 10 时显示全部，无数据时显示空状态文案。
18. 同一模型在榜单中的颜色与其在柱状图中的颜色一致。

### Activity 热力图（GitHub 风格）

19. 展示**最近一年**（约 53 周）按天聚合的活跃热力格子：列 = 周（顶部标注月份），行 = 星期（左侧标注周一/周三/周五）；今天的格子位于最后一列。
20. 格子颜色深浅跟随**当前指标**：无用量为空色；有用量按「有用量天数的四分位数」划分为 4 档深浅（浅 → 深），底部图例为「少 □□□□□ 多」共 5 个方块。
21. 热力图统计行展示四个统计值（口径均限定在热力图同一近一年周期内）：
    - **Longest streak**：最长连续天数——连续的日历天中每日总量均大于 0 的最长一段的天数。
    - **日均**：近一年总量 ÷ 365（日历天，非活跃天）。
    - **周均**：近一年总量 ÷ 52。
    - **总量**：近一年总量。
    - 四个统计值同样跟随指标切换。
22. 悬浮任一格子：tooltip 展示完整日期与当日数值；无数据格子 tooltip 显示当日数值为 0。
23. 热力图在窄屏下整体横向滚动，月份/星期标签随内容滚动；不压缩格子尺寸到不可辨。
24. 「每日」按**浏览器本地时区**的日历天聚合（与现有数据看板的日期展示口径一致）。

### 加载、错误与空状态

25. 各模块独立加载：页面进入时所有卡片显示骨架屏；某模块数据就绪后先行渲染，不互相阻塞。
26. 任一数据接口失败：对应模块显示错误占位与「重试」按钮，其余模块不受影响；重试仅重新请求失败模块。
27. 全新部署无任何数据时：汇总显示 0、环比显示 `0%`、柱状图/榜单显示空状态、热力图为全空色格子、统计值均为 0——页面不报错、不出现空白区块。

### 数据新鲜度

28. 页面展示的是按小时聚合落库的统计快照（落库周期由系统设置决定），与使用日志明细可能存在分钟级差异；页面不承诺实时性，也不展示「数据截至」时间戳。

### 国际化与可访问性

29. 所有文案走 i18n（英文 key + 中文翻译），含时间范围选项、指标名、图例、空状态、错误提示。
30. 指标切换与时间范围选择可键盘操作（Tab 聚焦 + 回车切换），控件具备可访问名称；热力图格子提供 aria 标签（日期 + 数值），装饰性图例标记 `aria-hidden`。
31. 数字格式化遵循当前语言环境的既有数字/金额格式工具（与现有数据看板一致）。
